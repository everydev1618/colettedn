How Colette works

01

You describe your project

"A marketplace for freelance designers" or "CLI tool that makes Kubernetes less painful" — whatever you're building.

02

Colette brainstorms

She generates 20-30 names across five vibes — clever, brandable, professional, playful, techy — spanning .com, .io, .ai, .dev and 70+ TLDs.

03

Only what's available

Every name is checked via RDAP — real-time registry lookups, not cached WHOIS. Taken names are crossed out. Available names are yours to register.

Runs locally

Your machine, your API key. Nothing stored, nothing tracked. Colette runs as a local server on port 3001.

Iterate naturally

Like "vettd" but want more? Ask Colette for variations. She keeps the conversation going until you find the one.

A Vega app

ColetteDN is built on Vega — an agent framework where AI apps are defined in a single YAML file. The entire brain of Colette is 41 lines of YAML — her personality, her tools, her workflow. Vega handles the rest: model orchestration, tool execution, the local server. No boilerplate, no glue code.
