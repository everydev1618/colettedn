Get started in 30 seconds

One command. Downloads the binary, verifies the checksum, prompts for your API key.

You'll need: an Anthropic API key (the installer will ask for it)
Install
curl -fsSL https://raw.githubusercontent.com/everydev1618/colettedn/main/install.sh | bash
Run
colettedn
What the installer does
✓ Detects your OS and architecture
✓ Downloads the latest release from GitHub
✓ Verifies SHA-256 checksum
✓ Runs a smoke test to confirm the binary works
✓ Validates your API key against Anthropic before saving
Or build from source
git clone https://github.com/everydev1618/colettedn.git
cd colettedn
go run cmd/colettedn/main.go

Requires Go 1.25+
